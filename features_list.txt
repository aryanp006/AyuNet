# AyuNet Feature List

## 🟢 Core TigerGraph Features

1. Symptom-to-Diagnosis Multi-hop Traversal [TIGERGRAPH CORE]
   - Patient speaks/types in Hindi, Tamil, Telugu, Bengali, Kannada, Marathi or English
   - Groq LLM (Llama 3 70B) extracts structured symptom array from natural language
   - GSQL multi-hop: Symptom nodes -> HAS_SYMPTOM edges -> Disease nodes, ranked by edge weight
   - Returns top-5 diagnoses with confidence % and supporting symptom count
   - Cytoscape.js animates the exact traversal path in real time

2. Drug Interaction Checker [TIGERGRAPH CORE]
   - Drug nodes connected by INTERACTS_WITH edges with severity: mild / moderate / severe
   - GSQL pattern matching finds all interaction paths across a given drug set in milliseconds
   - Returns severity rating, mechanism of interaction, and alternative drug suggestions
   - OpenFDA API provides real-time adverse event data — cached as new graph edges

3. Treatment Pathway Finder [TIGERGRAPH CORE]
   - Uses TigerGraph built-in shortest-path algorithm: Disease -> Specialist -> Treatment -> Drug -> Outcome
   - Edges weighted by clinical success rate and accessibility score
   - Returns fastest, safest, and most accessible routes simultaneously
   - Cytoscape.js renders the full pathway as an interactive directed graph

4. Rare Disease Detection (4-hop) [TIGERGRAPH CORE]
   - GSQL query traverses Symptom -> Disease (low prevalence) with 4-hop depth — SQL cannot replicate
   - Surfaces uncommon conditions sharing 1–2 atypical symptoms with patient profile
   - Returns rare conditions with ICD code, clinical notes, and recommended specialist type
   - Seeded with Orphanet / NORD rare disease ontology datasets

5. Comorbidity Risk Predictor (NEW — 4-hop) [NEW QUERY]
   - Hop 1: Patient -> existing Disease conditions (HAS_CONDITION edge)
   - Hop 2: Each Disease -> RiskFactor nodes (RISK_INCREASES edge)
   - Hop 3: RiskFactor -> other Diseases they elevate, accumulating multiplier scores
   - Hop 4: Filter to Diseases confirmed by LabTests the patient has NOT yet had
   - Risk score threshold (>1.5) triggers automatic doctor alert — impossible to replicate in SQL

6. Graph-Native PageRank on Disease Network [NEW QUERY]
   - Calls TigerGraph built-in tg_pagerank on Disease nodes to surface most connected conditions
   - Used to weight differential diagnosis — highly connected diseases ranked higher
   - Demonstrates native GDS library usage — a key differentiator vs. custom graph code

## 🟣 Indic Voice AI Features

7. Multilingual Voice Input/Output — Sarvam AI [INDIC TRACK]
   - Sarvam saarika:v2 STT transcribes patient speech in Hindi, Tamil, Telugu, Bengali, Kannada, Marathi
   - Sarvam bulbul:v1 TTS speaks diagnosis response back in the patient's own language
   - Language auto-detected by Groq LLM — no manual selection dropdown needed
   - Web Speech API retained as English fallback in Chrome/Edge
   - Free tier: 500 API calls/day — sufficient for full hackathon demo

8. Automated Patient Follow-up Call Engine [INDIC TRACK]
   - TigerGraph getDueFollowups() query finds every patient due for a call today
   - Query uses Protocol nodes with followup_days list — e.g. day 1, 3, 7, 14 post-surgery
   - FastAPI cron job fires daily: runs query -> generates Groq LLM script -> triggers Sarvam TTS call
   - Follow-up script personalised to patient condition, language, and prior response history
   - Twilio / Exotel free tier delivers actual phone calls

9. Structured Patient-Reported Data Collection [INDIC TRACK]
   - Patient speaks response to follow-up questions (pain level, medication taken, new symptoms)
   - Sarvam STT transcribes; Groq extracts structured JSON: {pain_score, took_medication, new_symptoms}
   - JSON written back to TigerGraph FollowUp vertex in real time via pyTigerGraph upsert
   - Risk flag auto-set if pain_score > 7 or new critical symptoms reported
   - Doctor dashboard receives instant WebSocket alert when risk flag triggers

10. Health Reminder System [INDIC TRACK]
    - TigerGraph query finds patients whose medication schedule is due today
    - Sarvam AI sends short voice reminder in patient's language: 'Aapki dawai lene ka samay ho gaya'
    - Reminder history stored as edges in TigerGraph — missed reminders automatically flagged
    - Zero incremental cost: Sarvam free tier + TigerGraph free tier

## 💡 Additional Recommended Features (Bonus / Extensibility)

11. Multilingual Audio OCR (Scan & Listen) [ENHANCEMENT]
    - Patient takes a picture of a medical bill or prescription.
    - System accurately extracts text (using Groq/Gemini vision) and instantly uses Sarvam TTS to read the findings allowed to the user in their regional Indic language.
    
12. Doctor Availability & Scheduling Graph [NEW CORE FEATURE]
    - Connect Specialist nodes to Availability time slots and Patient nodes.
    - Recommend optimal booking times based on traversal of patient schedule constraints, specialist load, and travel distance context.

13. Socio-Cultural Diet & Lifestyle Pathways [NEW QUERY / INDIC TRACK]
    - Expands the Treatment Pathway (Feature 3) by suggesting location-specific Indic diet modifications.
    - Uses Groq to map regional ingredients to dietary risk factors, helping rural/regional users follow health regimens without expensive imported dietary needs.
